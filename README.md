# 装机宅OLED测试

[打开在线测试](https://smartlanny.github.io/OLED-/)

离线运行的浏览器测试图案：低灰阶滚动拖影、灰阶与颜色过渡、纯色坏点检查、APL 面积窗口。手机和电脑连接同一局域网即可使用，不依赖 CDN。

## 直接运行

安装 Node.js 18 或更新版本后，在项目目录执行：

```sh
npm start
```

打开终端列出的局域网地址，例如 `http://192.168.1.100:5173`。手机需与电脑在同一网络。仓库包含构建好的 `app.js`、`app.css` 与 React 运行库，运行时无需先安装依赖，也无需外网。端口被占用时可使用 `PORT=5174 npm start`。

## 使用

- **拖影测试**：240 / 480 / 960 / 1920 CSS px/s；竖屏默认向下、横屏默认向右，支持反向；文字或无标签纯色方块；五组预设、独立 G0–255 前景与背景灰阶、三档字号。
- **色阶与纯色**：始终从上向下展开，横竖屏不改变方向；全灰阶、近黑渐变、暗部展开、12 档近黑灰阶、六色渐变，以及黑白红绿蓝灰和自定义纯色。
- **APL 窗口**：1–100% 面积预设，独立窗口与底色灰阶。优先生成正方形，超出短边时改为矩形，始终保持指定面积。
- 选择测试后尝试全屏，直接显示纯净画面。双击 / 连续轻点两次测试画面或按 **H** 打开完整悬浮面板，再次双击或点关闭收起。
- 打开面板时滚动自动暂停，收起后继续；调整灰阶和图案立即生效。拖动面板标题可移动位置，标题获得焦点后也可用方向键移动。面板内部独立滚动。
- **Esc** 或面板返回按钮回到菜单。
- 全屏取决于浏览器支持；不支持时仍可正常测试，面板内可再次尝试。支持屏幕唤醒锁的浏览器会尝试保持常亮；普通局域网 HTTP、系统省电或权限设置可能使其不可用，可手动延长手机自动锁屏时间。

## 测试口径

先固定系统亮度，关闭自动亮度、护眼与自适应色温；跨设备对比保持设置和环境一致。**测量前隐藏控制**，面板自身发光会改变实际平均画面亮度。

窗口面积以当前网页视口为分母，不包含浏览器工具栏、系统状态栏或网页覆盖不到的物理显示区域。圆角和挖孔不作物理面积校正。

页面显示的「平均信号电平」是 `100 × (面积比例 × 窗口码值 + (1 − 面积比例) × 底色码值) / 255`。它不是经过 EOTF 转换的线性光 APL，也不是实测亮度；只有白窗黑底时，数值与面积比例相同。

滚动速度为 CSS 像素 / 秒，不是面板物理像素 / 秒。动画由浏览器逐帧调度，后台暂停，恢复时跳过挂起时间。页面不能直接测量屏幕亮度、PWM、灰阶响应时间或面板刷新率。

## 开发与检查

```sh
npm ci
npm run build
npm test
npm run package:site
```

修改 `app.jsx` 或 `src.css` 后需要重新构建；提交源码时同时提交生成的 `app.js`、`app.css`。开发依赖版本由 `package-lock.json` 固定。`BUILD_OUT_DIR=/tmp/oled-build npm run build` 可将构建结果写入另一目录。

`npm run package:site` 将运行文件复制到 `dist/`，可直接部署为静态站点。GitHub Actions 在主分支更新后发布 GitHub Pages。在线首次加载需要网络；离线使用请下载仓库并运行本地服务。

局域网服务只公开运行所需的 HTML、CSS、JS、图标和第三方许可；不公开源码、Git 信息、日志、测试或 `node_modules`。不要把它当作通用文件服务器。

源版本对比与验证记录见 [MERGE-NOTES.md](MERGE-NOTES.md)。

React 18.3.1 与 ReactDOM 18.3.1 的第三方许可见 [vendor/LICENSE-react.txt](vendor/LICENSE-react.txt)。
